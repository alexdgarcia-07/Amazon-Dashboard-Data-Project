# Amazon-Dashboard-Data-Project
An end to end data analysis project analyzing real Amazon India clothing sales data to provide business recommendations.
##  Executive Summary

* **Total Revenue:** ₹78.59M
* **Total Transactions:** 117K
* **Key Category Leader:** Sets & Kurtas account for the vast majority of total sales revenue.
* **Top Performing Sizes:** Medium (M), Large (L), and Extra Large (XL) drive core volume.

---

##  Built With

* **Power BI Desktop** – Data modeling, DAX measures, and interactive reporting
* **Power Query (M)** – Data extraction, transformation, and cleaning
* **Dataset:** Amazon India E-Commerce Sales (Kaggle)

---

##  Key Dashboard Features

* **KPI Summary Cards:** High-level overview of revenue and order volume.
* **Category Performance Breakdown:** Visualizes sales share across categories (Sets, Kurtas, Western Dress, Tops, etc.).
* **Size Analysis:** Examines revenue distribution from XS to 6XL to optimize inventory planning.
* **Dynamic Slicers:** Interactive filtering by Category, Month, and Order Status.
